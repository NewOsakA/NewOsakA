## Selected projects

### 01 · [RogueType](https://github.com/NewOsakA/RogueType)
A typing-powered roguelike base defense game built with **Unity and C#**, with experimental ONNX-based adaptive difficulty.

My contributions include menu and settings interfaces, save-selection UX improvements, game balancing, and asset integration within a collaborative project.

### 02 · [Fanlore](https://github.com/NewOsakA/Fanlore)
A fandom community platform built with **Django and PostgreSQL**, supporting creative content, events, and social features.

My contributions include profiles and following, home-page filtering, pagination, interface refinements, and automated tests.

### 03 · [Health-Jam](https://github.com/NewOsakA/Health-Jam)
An individual coursework project built with **Node.js, Express, Handlebars, and SQLite** for managing patients, doctors, appointments, and accounts.

The project brings together relational data, session-based authentication, role-based access, and a responsive interface. Developed for Web Development Fundamentals at Jönköping University, with AI assistance acknowledged in the source.

### 04 · [Diabetes-ML](https://github.com/NewOsakA/Diabetes-ML)
An educational **Python and PyTorch** classification study investigating class imbalance in BRFSS health indicators.

Includes baseline comparisons, weighted neural networks, nested development cross-validation, saved inference models, tests, and documented evaluation tradeoffs. [Read the experiment report](https://github.com/NewOsakA/Diabetes-ML/blob/main/results/REPORT.md).
